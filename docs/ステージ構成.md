# ステージ構成（1〜6面・面内の進行を含む）

このファイルは、他の人（または別の AI）へ現状を説明して相談するための資料です。2026-09-16 時点のコードから起こしました。
数値はすべて実装そのままで、フレーム数は **30fps 固定**（メガクラッシュ中と最終面の一部だけ 60fps）です。

---

## 0. ゲームの基本

- 機種: MSX turboR（V9958 / R800）。画面は SCREEN5（256×212、16色パレット）。
- 見下ろし型の縦スクロールシューティング。自機は零戦（低空飛行）。
- 全6面。1〜5面は「海の区間 → 敵の大型艦との戦い」、6面（最終面）は巨大機との一騎打ち。
- 操作: 十字＝移動 / A＝射撃 / A+B＝宙返り（16フレーム、クールダウン45フレーム＝1.5秒。回っている間は撃てず、敵弾は下を抜ける） / B単押し＝メガクラッシュ（1挑戦につき3回）。
- 残機: 設定で 2 / 3 / 5。1機あたりの耐久は設定で 1〜9（既定1）。
- 難易度（設定）で敵の発射間隔が変わる: EASY=1.25倍遅い / NORMAL=等倍 / HARD=0.75倍速い。加えて「レイジ」（後述）で 2/3 倍。

### 面の進行（1〜5面の共通）
1. **開始カード**（面番号・TARGET・艦名・艦のシルエット）＋ファンファーレ。
2. **海の区間（phase 0）**: 敵艦はまだ見えない。カメラは 1ドット/フレームで前進。長さは **160フレーム（約5.3秒）**。
   - 敵戦闘機が面ごとの間隔で湧く（下表）。半分は面固有の挙動、半分は蛇行。
   - 各機は 50% の確率で自機狙いの弾を撃つ（40フレーム間隔、狙い＋±3方向の散らし）。
   - **銀＋赤帯の敵機が1機だけ出る**（パワーアップ用。まっすぐゆっくり降り、撃ってこない）。
   - BGM は海の共通曲。
3. **艦との戦い（phase 1）**: 艦が画面に入った瞬間に BGM が面別へ切替。カメラは艦首↔艦尾を 1.6ドット/フレームで往復（片道 約178フレーム＝6秒）。艦は横に蛇行する。
   - 攻撃対象は **主砲4基（スプライト）** と **対空砲23基（背景に描かれている）**。
   - 面固有の兵装（下表）。
   - 生存している主砲が1基になると **レイジ**（全ての発射間隔が 2/3 に短縮）。
   - 主砲は一定間隔で**全方位12発の弾幕**を撃つ（48フレームに1回、生存している画面内の1基から）。
4. **全滅で撃沈**: 誘爆（30フレーム）→ 船尾から水没（水面が船首へ向かって上がる。約4〜8秒）→ 結果画面（撃破!! / [艦名] SUNK / スコア）→ 次の面へ。
5. ミス（自機撃墜）: その面の最初（海の区間）からやり直し。パワーアップは初期に戻る。

- 主砲の発砲欄は「発射間隔・自機狙いの n 方向・弾速」。面が進むほど間隔が短く、方向が増え、弾が速くなります。
- 主砲には **ゼロ距離抑え込み**があり、自機が近い（半径 26→18 ドット、面が進むほど狭い）と発射しません。肉薄して安全に撃ち込めるのが上級者の解法です。
- 対空砲は、前14基が大型（時限信管の弾が空中で3破片に割れる）、後9基が小型（通常弾）。

### 破壊物の耐久（威力は「半分単位」で数える。通常の自機弾は1発 2）

| 主砲（4基） | 40 / 48 / 56 / 64 / 80（面順） | 20 / 24 / 28 / 32 / 40 |
| 大型対空砲（14基） | 14 / 16 / 18 / 22 / 26 | 7 / 8 / 9 / 11 / 13 |

★パワーアップ段階3は「3方向×威力3倍×貫通」で火力が通常の約5倍になる。耐久はそれを見込んだ値。

### 得点
- 敵戦闘機・停泊機 10 / 艦載機 20 / 小型対空砲 20 / 大型対空砲 30 / 主砲 60 / 増槽（最高段階で取ったとき）1000。

## 2. パワーアップ（2026-09-16 追加）

- 海の区間に1機だけ出る**銀＋赤帯の敵機**を落とすと、その場に**増槽**（落下式燃料タンク）が出て、海と一緒に下へ流れる。触れると取得。画面の下に抜けると消える。
- 取るたびに段階が上がる（最高3）。ミス・新しいゲーム・最終面の開始で通常に戻る。

| 段階 | 弾 | 発射間隔 | 威力 |
|---|---|---|---|
| 通常 | 赤い細い弾1発（縦） | 6フレーム | 2 |
| 1 | 太い弾3発（縦・左上・右上）赤／先端が白 | 10フレーム | 4 |
| 2 | 同上 白／根元が赤 | 10フレーム | 5 |
| 3 | 同上 全部白。**貫通**（同じ相手には1回だけ当たる） | 10フレーム | 6 |

- 増槽のチャンスは1面につき1回。ミスしなければ最高段階になるのは早くて4面。

## 3. 最終面（6面）XB-19

- 画面を走査線で3つの帯に分ける: 上端＝スコア表示 / 中＝**ボス帯（スプライト2倍拡大）** / 下＝自機帯。境目に**壁**があり、自機は壁より上へ行けない。
- 敵は**ボス1体のみ**。ほかの敵機は出ない。自機は**初期装備**（パワーアップ無し・ボム0）。宙返りだけが回避手段。
- 弾（自機弾・敵弾）はスプライトではなく**背景に描く**（ボス帯は1走査線8枚をボスと壁が使い切るため）。
- BGM は「壮大なイントロ（576フレーム）→ 本編のループ」。**ボスの登場演出はイントロと同じ長さ**。

**面内の進行（数字は曲の開始からのフレーム）**
1. 0〜96: 待機。壁が左右から1枚ずつ組み上がる（低い「ががが」という音つき）。
2. 96〜384: ボスが**等倍**で旋回しながら降りてくる（13コマ）。
3. 384〜576: **2倍拡大**へ切り替わって迫る（13コマ）。
4. 576〜: 交戦。ボスは左右に移動し、傾き（3段階）で機体が傾く。150フレームごとに全方位弾。弱点は**エンジン4・銃座2**の計6か所。被弾すると機体全体が明るい灰で光る。
5. 全弱点の破壊で撃墜演出（きりもみしながら落ちる、24コマ）。高度が下がるにつれ影が近づく。
6. 結果画面（XB-19 DOWN）→ エンディング（スタッフロール）。

## 4. 技術的な制約（中ボスを足すときに効くもの）

- **スプライト**: 16×16、1色/行（2枚重ねで OR 色）。**同時32枚**、**1走査線に8枚**まで。9枚目以降は消える。
  - 今の使用: スコア等のHUDが9枚、自機1＋影1、敵機と影、自機弾（通常1発／パワーアップ時は最大9枚）、敵弾、爆発。
  - 艦との戦いでは、主砲の弾幕用に**12枚を予約**している（走査線ごとに表を切り替えて、同じ32枚を2回使う仕組み）。
- **背景**: 海は16行のテンプレートを敷き詰め、艦は 256×496 の絵を画面外のVRAMに一度だけ描いてある。表示は256行のリングで、縦スクロールはレジスタ1本（描き直し無し）。
- **拡大（MAG）**: スプライト全体に効くので、帯で区切って使う（最終面と津波のみ）。等倍と混在させるには走査線での切り替えが要る。
- **コード置き場の残り**（2026-09-16）: 常駐コード 1288B（性能計測用ビルドは 291B）/ 通常面のオーバレイ 609B / 毎フレームRAM実行のコード 73B / 最終面のオーバレイ 46B / ROM は 512KB 中 240KB 未使用。
- **フレーム**: 30fps 固定。1フレームの処理は VDP の転送待ちが支配的。
- 敵弾の同時数は20発でリミッタ。

## 5. 相談したいこと（未着手）

**中ボス（大型機）をどのタイミングで、どのように混ぜるか。**

- 現状、1〜5面は「海の区間（約5秒）→ 艦との戦い（撃破するまで）」の2段だけで、区切りが1つしかありません。
- 最終面の驚きを残したいので、中ボスの大きさは**スプライト 2×2（32×32ドット）まで**と決めています（最終面のボスは 2倍拡大で 128×80 相当）。
- 候補として出ている案:
  - 海の区間の終わりに、編隊を率いる大型機を出す。
  - 艦との戦いの途中（主砲を2基壊した時点など）に割り込ませる。
  - 面と面の間に独立した区間を作る。
- 決めたいのは、**どの面から出すか / 1面あたり何回か / どの段のあとに置くか / 撃破報酬（増槽を出すかどうか）/ 時間の目安**です。
