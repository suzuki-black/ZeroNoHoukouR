# 零の咆哮 改 仕様書

本書はゲーム内容（プレイ仕様）を記す。内部構造は [ARCHITECTURE.md](ARCHITECTURE.md) を参照。

> 本作に登場する兵器・艦艇・航空機は史実の名称を参考にしたフィクションであり、実在兵器の
> 正確な再現を意図したものではない。形状・色彩・性能は創作上の都合で変更されている。また
> MSX のハード制約上、シルエットが実物と異なる場合がある。

---

## 1. 基本

- 1 人用・縦スクロールシューティング。自機＝日本海軍の艦上戦闘機（零戦）。
- 1 ステージは**画面カット無しの地続きの縦スクロール**。海（空戦）で始まり、そのまま敵大型
  艦との戦闘へ接続する。艦上のすべての火点を撃破するとクリア。

## 2. 操作

| 入力 | 動作 |
|------|------|
| カーソル／ジョイスティック | 8 方向移動 |
| スペース／トリガー A | 発射・決定 |
| M ／ トリガー B | （隠しコマンド用） |

自機弾は上方向へ直進。自機はプロペラ回転アニメと海面への落ち影を持つ。

## 3. 画面遷移

```
タイトル ──(A)──────────────► ステージ開始カード ─► 海(空戦) ─► 戦艦戦 ─► 撃破演出
   │                                                                          │
   └─(隠しコマンド)─► 設定メニュー ─(戻る)─► タイトル      次面あり◄──────────┘
                                                          最終面クリア ─► エンディング ─► タイトル
```

- **開始カード**：BGM 停止（無音）→ カード（STAGE n / TARGET / 艦名・シルエット）→ その裏で
  ステージ準備 → 開始ファンファーレ → 余韻 → メイン BGM 開始 → ゲーム開始。
- **撃破演出**：艦全体が炎に包まれる → 「撃破!!」→ SCORE / HI → 勝ちどきファンファーレ →
  次面（またはエンディング）。

## 4. ステージ（全 5 面）

各面のボス艦と、海イントロに出る戦闘機（＝ボス艦の所属海軍の当時の典型機）。

| 面 | ボス艦 | 海イントロ機 | 固有兵装 |
|----|--------|--------------|----------|
| 1 | ビスマルク級 戦艦 | Bf109（独） | ― |
| 2 | 航空母艦（エセックス級） | F4U コルセア（米） | 艦載機 F6F を甲板から射出し自機を追尾 |
| 3 | フッド（巡洋戦艦） | スピットファイア（英） | 舷側から潜水艦ミサイル（浮上→弱誘導→8 方向炸裂） |
| 4 | 双子戦艦（ネルソン級 姉妹） | Fw190（独） | 左右の艦から弾が中心へ収束→合体して自機狙いの大弾 |
| 5 | アイオワ級 戦艦 | F6F ヘルキャット（米） | 画面端から連続空襲（F4U, ホバー無しの即追尾） |

海イントロ機は所属国で飛び方が異なる（独＝急降下／英＝横蛇行／米＝直進で数押し）。**機体は移動方向へ
機首を向ける 8 方向スプライト**（手続き生成の 8 方向×3 サイズ。国別の雰囲気は翼幅で作り分け）で、
mode2 の行別カラーで陰影を付ける。**各面とも固有の飛び方に蛇行を混ぜて出現数を増やしてある**ので、
真下だけでなく斜めにバンクする機体が常に混ざる（v0.2.0）。空母/アイオワの艦載機は自機を追尾して
8 方向に旋回し、空母発艦機は小→中→大へ成長する浮上アニメで飛び立つ。

## 5. 敵の火点

### 主砲（各面 4 基・破壊可能）
- 自機を狙って旋回する 2 連装砲身。HP5。命中で白フラッシュ、撃破で炎上残骸化。
- 発砲は面が進むほど激化（発射間隔↓・弾数↑・弾速↑）。

| 面 | 発射間隔 | 弾 | 備考 |
|----|----------|----|------|
| 1 | 遅い | 3-way 扇 | 教育的 |
| 2 | ↓ | 4-way | |
| 3 | ↓ | 4-way | |
| 4 | ↓ | 5-way | |
| 5 | 速い | 5-way・高速弾 | |

- **ゼロ距離抑え込み**：主砲は自機が実効半径内（≒至近）に居ると発射をスキップする。安全に
  連射するには肉薄して撃たせないのが最速撃破のコツ。実効半径は難易度で増減。

### 対空砲（各面 23 基・破壊可能）
- 前 14 基＝大型（時限信管エアバースト弾、HP2）／後 9 基＝小型（通常小弾、HP1）。
- 面別に発射間隔が短くなる（激しくなる）。艦が画面帯に居るときだけ発砲。

### レイジ
- 生存主砲が残り 1 基になると全火点の発砲が速射化する。

## 6. スコア・残機

- スコアは 16bit（撃破得点は小さめに調整）。ハイスコアを保持。

| 対象 | 得点 |
|------|------|
| 海イントロ機 | 10 |
| 艦載機（追尾機） | 20 |
| 対空砲（大型） | 30 |
| 対空砲（小型） | 20 |
| 主砲 | 60 |

- HUD：上段にスコア 5 桁（白）＋ 残機＝零戦シルエット icon ＋ 予備機数（9 頭打ち）。
- **被弾**：自機は耐久（設定）を持ち、被弾で 1 減。耐久が残れば約 1.5 秒の無敵点滅で生存、
  尽きると撃墜。撃墜されると残機を 1 消費して**その面の最初から**やり直し（全火点復活）。
- **ゲームオーバー**：残機が尽きると GAME OVER 画面。コンティニュー ON なら CONTINUE/TITLE を
  選択（CONTINUE＝残機初期化・スコア保持で同面再開）、OFF ならタイトルへ。

## 7. クリア／ミス条件

- **クリア**：その面のすべての火点（主砲 4＋対空砲 23）を撃破する。
- **ミス（撃墜）**：自機の耐久が尽きる。

## 8. 難易度（設定メニュー）

設定メニュー（隠しコマンドから開く）で調整可能。

| 項目 | 内容 |
|------|------|
| 難易度 | EASY / NORMAL / HARD（発砲間隔を EASY×1.25 / HARD×0.75、抑え込み半径も増減） |
| 残機 | 予備機数 |
| 耐久 | 自機 1 機あたりの被弾耐久 |
| ステージ選択 | 開始面 |
| コンティニュー | ゲームオーバー時の継続可否 |
| （その他） | 開発用の設定を含む |

## 9. 手応え（ジュース）

- **ヒットストップ**：撃破・被弾で数フレーム画面を凍結。
- **画面揺れ**：撃破・被弾で数フレーム縦にジッタ。
- **破壊点数ポップアップ**：敵/砲台の撃破時、加算点(10/20/30/60)を破壊位置の真上に数字スプライトで
  約1.5秒表示（その場に固定・浮遊なし）。上端外に出る場合はそのまま見切れる。
- **常時炎上**：破壊した火点はスクロール中も燃え続け、破壊済みが一目で分かる。
