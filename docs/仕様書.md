# 真 零の咆哮 仕様書（ゲーム仕様とステージ構成）

> 遊びの仕様と、全6面の中身をまとめた文書。数値はすべてコードの実装値（2026-09-23 時点）。
> フレーム数は **30fps 固定**で数える（メガクラッシュ中と最終面の一部だけ 60fps で回る）。
> 実装の置き場所は [アーキテクチャ](ARCHITECTURE.md)、作業の記録は [ROADMAP](ROADMAP.md) を参照。

---

## 1. 基本

- **機種**: MSX turboR（V9958 / R800）。画面は SCREEN5（256×212・16色パレット）。
- **ジャンル**: 1人用・見下ろし型の縦スクロールシューティング。自機は零戦（低空飛行）。
- **構成**: 全6面。1〜5面は画面カットの無い1本のスクロールで「海 → 中ボス → 海 → 敵の大型艦」。
  6面（最終面）は巨大機 XB-19 との一騎打ち。
- **クリア条件**: 1〜5面は艦の火点（主砲4基＋対空砲23基）を全部壊す。6面は弱点6か所を壊す。

## 2. 操作

| 入力 | 動作 |
|------|------|
| カーソルキー／ジョイスティック | 移動（3ドット/フレーム。画面内にクランプ） |
| スペース／キーボード **A**／トリガーA | 発射・決定 |
| キーボード **B** または **M**／トリガーB（単押し） | メガクラッシュ（ボム） |
| 撃ちながら B（A＋B） | 宙返り |

- 自機弾は通常＝赤い細い弾を真上へ1発（**6フレーム間隔**）。パワーアップ後は**縦・左上・右上の3発**（**10フレーム間隔**）。
- タイトル画面で**コナミコマンド（↑↑↓↓←→←→BA）**を入れると設定メニューが開く。

## 3. 画面遷移

```
タイトル ──トリガ──► ステージ(全6面) ──最終面クリア──► エンディング ──► タイトル
   └─コナミコマンド─► 設定メニュー ──START──► ステージ
```

**1〜5面の面内の進行**

1. **開始カード**（面番号・TARGET・艦名・艦のシルエット）＋ファンファーレ。
2. **海1**（144フレーム）: 敵艦はまだ見えない。カメラは 1ドット/フレームで前進。敵戦闘機が湧く。BGM は海の共通曲。
3. **フェードアウト**（32フレーム）: 残っている敵機・敵弾を4段階で海の色へ溶かして消す。
4. **中ボス**（面ごとに1体。§7）。この間は縦スクロールが止まる。BGM は中ボス専用曲。
5. **海2**（144フレーム）: カメラを 144 ドット巻き戻して、海1と同じ長さをもう一度走る。
6. **フェードアウト → 警報**（150tick＝2.5秒）: BGM を止めてサイレン。漢字パネル「敵艦発見」＋`ENEMY FLEET SIGHTED`。
7. **艦との戦い**: 艦が画面に入った瞬間に面別 BGM へ切替。カメラは艦首↔艦尾を 1.6ドット/フレームで往復し、艦は横に蛇行する（振幅 ±40ドット）。
8. **撃沈**: 誘爆（30フレーム）→ 船尾から船首へ水面が上がる水没 → 静まる（16フレーム）→ 結果画面（`撃破!!` / `[艦名] SUNK` / SCORE / HI）→ 次の面へ。

**6面の進行**: 警報「敵大将発見」→ 電文を一文字ずつ打電 → **増槽と爆弾を投棄** → ボス登場（曲のイントロと同じ長さ）→ 交戦 → 撃墜 → 結果画面（`XB-19 DOWN`）→ エンディング。

- **ミス**: その面の最初（海1）からやり直し。パワーアップは 0 に戻り、ボムは3本に補充される。
- **残機が尽きたら**: 継続ONならコンティニュー（残機を戻して同じ面から。スコアは保持）、OFFならタイトルへ。

## 4. ステージ一覧

| 面 | 目標（艦） | 中ボス | 時間帯・天候 | 海の敵機 | 出現間隔 | 主砲の発砲 | 対空砲の間隔 | 艦の固有兵装 |
|---|---|---|---|---|---|---|---|---|
| 1 | BISMARCK（独戦艦） | Fw 200 コンドル | 昼 | 独機（急降下） | 20 | 56フレーム・3方向・弾速3 | 140 | なし（教育面） |
| 2 | CARRIER（米空母 ESSEX） | PBY カタリナ | 夕焼け | 米機（直進） | 14 | 50・4方向・4 | 132 | 甲板の停泊機が発艦して追尾（同時3機・120フレーム間隔） |
| 3 | HOOD（英巡洋戦艦） | 駆逐艦2隻 | 荒天（稲光と雷鳴） | 英機（蛇行） | 20 | 44・4方向・4 | 84 | 舷側から潜水艦ミサイル（浮上→弱誘導→8方向に炸裂。同時3発・90フレーム） |
| 4 | TWINS（独 双子艦） | He 111 ×2 | 朝霧 | 独機（急降下） | 20 | 38・5方向・4 | 64 | 左右の艦の弾が中心へ収束し合体して自機狙いの大弾（同時2組・80フレーム） |
| 5 | IOWA（米戦艦） | P-61 ブラックウィドウ | 夜戦 | 米機（直進） | 14 | 32・5方向・5 | 40 | 画面の左右端から艦載機が来て即追尾（同時4機・45フレーム） |
| 6 | XB-19（巨大機） | なし | 昼 | 出ない | — | — | — | §8 |

- 海の敵機は**半分が面固有の挙動、半分が蛇行**。**50%だけが発砲**する（40フレーム間隔・自機狙い±3方向の散らし・弾速3）。
- 海の区間には**銀＋赤帯の敵機が1機だけ**出る（まっすぐゆっくり降り、撃ってこない）。落とすと増槽（§6）。
- 主砲には**ゼロ距離抑え込み**があり、自機が近い（半径 26→18 ドット。面が進むほど狭い）と撃ってこない。肉薄して安全に撃ち込めるのが上級者の解法。実効半径は難易度で ±（EASY +12 / HARD −8、下限8）。
- 対空砲は前14基が大型（時限信管の弾＝弾速2・信管42フレームで下向き3破片に割れる）、後9基が小型（通常弾）。同じフレームに撃つのは2基まで。
- **レイジ**: 生存している主砲が1基になると、全ての発射間隔が 2/3 に短縮され、さらに**全方位12発の弾幕**が 48フレーム間隔で加わる。
- 敵弾（スプライト）の同時数は **20発**でリミッタ。中ボスの弾はこの枠の外（背景に描くため）。

## 5. 耐久と得点

耐久は「半分単位」で数える（通常の自機弾＝1発 2）。

| 対象 | 耐久（1〜5面の順） | 通常弾での発数 |
|---|---|---|
| 主砲（4基） | 40 / 36 / 56 / 64 / 80 | 20 / 18 / 28 / 32 / 40 |
| 大型対空砲（14基） | 14 / 16 / 18 / 22 / 26 | 7 / 8 / 9 / 11 / 13 |
| 小型対空砲（9基） | 8 / 9 / 10 / 12 / 14 | 4 / 5 / 5 / 6 / 7 |
| 敵戦闘機・艦載機・停泊機 | 1発 | 1 |
| 最終面の弱点（エンジン4） | 40 | 20 |
| 最終面の弱点（銃座2） | 60 | 30 |

> 2面の主砲だけ軟らかい（36）のは、左前の砲が停泊機の奥にあって当てにくいため。

| 対象 | 得点 |
|---|---|
| 海の敵機・空母の停泊機 | 10 |
| 艦載機（追尾機） | 20 |
| 小型対空砲 | 20 |
| 大型対空砲 | 30 |
| 主砲・最終面の弱点 | 60 |
| 中ボス（1・2・5面） | 500 ＋ 残り時間ボーナス（残り1秒＝10点） |
| 中ボス（3・4面） | 1隻／1機ごとに 300。2体目で残り時間ボーナス |
| 増槽（最高段階で取ったとき） | 1000 |

- スコアは 16bit（65535 で頭打ち）。撃破位置の真上に加算点が**1.5秒**表示される（同時5個まで・4桁まで・画面内にクランプ）。
- ハイスコアはタイトルと結果画面に出る。

## 6. パワーアップ（増槽）

海の区間に1機だけ出る銀＋赤帯の敵機を落とすと、その場に**増槽**が出て海と一緒に流れる。触れると取得、画面の下へ抜けると消える。チャンスは**1面につき1回**。

| 段階 | 弾 | 発射間隔 | 威力 |
|---|---|---|---|
| 通常 | 赤い細い弾1発（縦） | 6フレーム | 2 |
| 1 | 太い弾3発（縦・左上・右上）赤／先端が白 | 10フレーム | 4 |
| 2 | 同上 白／根元が赤 | 10フレーム | 5 |
| 3 | 同上 全部白。**貫通**（同じ相手には1回だけ当たる） | 10フレーム | 6 |

- 段階は画面下中央の**山形のアイコン**で示す（通常＝1本、最高＝4本）。
- ミス・新しいゲームで 0 に戻る。最終面では持ったまま始まり、電文のあとの**投棄**で 0 になる。
- 最高段階でさらに取ると 1000 点。フェードアウトのときに画面に残っている増槽は、取ったことにしてくれる。

## 7. メガクラッシュ（ボム）と宙返り

### メガクラッシュ
- **B単押し**で発動。1回の挑戦につき **3回**（面の開始とミス再開で満タンに戻る）。**中ボス撃破で+1**（上限3）。
- 演出は全78フレーム。地鳴り → 稲妻3回と雷鳴 → 稲妻を消す → **画面幅の水の壁（拡大スプライト）が等加速度で駆け上がる** → BGM は続きから再開。
- **画面上の敵弾が消える**のは途中（残り24フレームの時点）。
- この間だけ 60fps で回る。拡大が全スプライトに効くので、波の間は HUD も敵も出ない。
- **使えない場面**: 宙返り中／警報の表示中／**5面の中ボス戦**（電探妨害で不発。`JAMMED` の表示と砂嵐の音だけ）。最終面は投棄して 0 本。

### 宙返り
- **A＋B**で発動。長さ **16フレーム**、クールダウン **45フレーム（1.5秒）**。回数制ではない。
- **無敵ではない**。当たり判定そのものを行わず、**敵弾は自機の下を抜けていく**（弾は消えない）。
- 代償として、回っている間は**撃てない**し**ボムも出せない**。
- 見た目は機体が縦に縮んで大きくなり、背面を見せて戻る。影が離れて高く上がって見える。抜けた瞬間に衝撃波のリング。専用の効果音（低いうなりが上ずる 0.77秒）。
- 面の開始・ミス再開では持ち越さない。

## 8. 中ボス（5種）

海1の終わりに1回だけ出る。撃破すると**ボム+1**と得点。時間切れで逃げられると得点なし。
被弾すると当たった機だけ1フレーム白く光り、突進や斉射の前には12フレームの予告（白く明滅）が入る。
耐久が半分を切ると**手負い**（エンジンが燃え、動きが速くなる）。

| | 1面 Fw 200 | 2面 PBY カタリナ | 3面 駆逐艦2隻 | 4面 He 111 ×2 | 5面 P-61 |
|---|---|---|---|---|---|
| 大きさ | 64×64（32方向） | 高さで6段階 43〜60ドット（16方向） | 176×24 を2隻（背景に描く） | 64×64 ×2機（32方向） | 48×48 を2倍拡大して 96×96（9方向） |
| 耐久 | 200（通常弾100発） | 160（80発） | 1隻180（計360） | 1機120（計240） | 240（120発） |
| 攻撃 | 向き直り→突進。向き直る間に自機狙い3方向 | 低空で16フレームごとに射撃。体当たり | 蛇行しながら砲塔が1基ずつ射撃、4回に1回は4基の斉射 | 画面中心について点対称に2機で突進。自機狙い2方向 | 上に居座り渦巻きの弾幕＋扇11発 |
| 逃げる | 40秒 | 40秒 | 40秒（2隻とも嵐に消える） | 45秒 | 45秒 |
| 特記 | 弾は背景に描く | 高く飛んでいる間は当たらず、自機の上を通る | 影は無い（艦）。帯ごと横に動かす | 弾は背景に描く。霧から現れる | 画面全体が2倍拡大。HUD は背景に描く。ボム不可 |

## 9. 最終面（6面）XB-19

- 画面を走査線で3つの帯に分ける。上端＝スコア表示／中＝**ボス帯（2倍拡大）**／下＝自機帯。境目に**壁**があり、自機は壁より上へ行けない。
- 敵は**ボス1体のみ**。弾（自機弾・敵弾）はスプライトではなく**背景に描く**（ボス帯は1走査線8枚をボスと壁が使い切るため）。
- 自機は投棄で**初期装備**（パワーアップ無し・ボム0）。避ける手段は移動と宙返りだけ。
- 進行（曲の開始からのフレーム）:
  1. 0〜96: 待機。
  2. 96〜384: **等倍**で旋回しながら降りてくる。
  3. 384〜552: **2倍拡大**へ切り替えて迫る。同時に**壁**が6フレームに1枚ずつ、外側から内側へ8枚組み上がる（低い地鳴りの音）。
  4. 576〜: 交戦。左右に移動し、傾きが3段階で変わる。**150フレームごとに扇状の弾11発**。被弾すると機体全体が明るく光る。
  5. 弱点6か所（エンジン4＝64フレーム間隔の自機狙い±2／銃座2＝44フレーム間隔の3方向）をすべて壊すと、きりもみしながら落ちる。高度が下がるにつれ影が近づく。
  6. 結果画面（`XB-19 DOWN`）→ エンディング（スタッフロール）。

## 10. 難易度と設定メニュー

タイトル画面でコナミコマンド（↑↑↓↓←→←→BA）を入れると開く。

| 項目 | 内容 |
|---|---|
| DIFFICULTY | EASY（間隔1.25倍＝遅い）／NORMAL／HARD（0.75倍＝速い）。全系統の発砲・出現間隔に掛かる |
| LIVES | 残機 2 / 3 / 5（既定3） |
| DURABILITY | 1機あたりの耐久 1〜9（既定1＝一撃死） |
| STAGE | 開始面 1〜6 |
| CONTINUE | 残機が尽きたときのコンティニューの可否 |
| INVINCIBLE | 無敵（被弾を完全に無効。開発用） |
| VIEW | 画面ビューア。GAME／CARD（開始カードのみ）／RESULT（結果画面のみ）／ENDING（開発用） |
| START GAME | 決定してゲームへ |

- 難易度はレイジ中にさらに 2/3 が掛かる。
- 被弾すると **90フレーム（約3秒）**の無敵点滅。耐久が残っていればその場で復帰、尽きるとミス。

## 11. 手応え（ジュース）

| 要素 | 内容 |
|---|---|
| ヒットストップ | 被弾で5フレーム、主砲撃破で4フレーム、画面を止める |
| 画面揺れ | 被弾12 / 主砲撃破8 / 対空砲撃破6 フレーム、振幅 ±2ドット |
| 衝撃波 | 砲台撃破・被弾・宙返りの抜けで、震源から上下へ広がる縦のうねり（14フレーム・7ドット/フレーム・振幅最大10ドット） |
| 点数ポップアップ | 撃破位置の真上に加算点を1.5秒 |
| 常時炎上 | 壊した火点はスクロール中も燃え続ける（2コマの明滅） |
| パレット演出 | 被弾の赤染め、撃破の白フラッシュ、面ごとの時間帯・天候（昼／夕焼け／荒天の稲光／朝霧／夜戦） |
| 音 | 面別BGM・中ボス曲・警報・最終面のイントロ付きBGM。勝ちどきのファンファーレ |

## 12. ハードの制約（設計の前提）

- **スプライト**: 16×16・1色/行（2枚重ねで色を足す）。**同時32枚・1走査線8枚**。
  走査線の途中でスプライト表を切り替えて、上下の帯で同じ32枚を使い回している。
- 枠の配分は可変。HUD が9枚、中ボス戦は中ボスが16〜18枚を取り、パワーアップのアイコンに1枠を予約する。
  中ボス戦で自機と弾に残るのは4枠しかないので、**中ボスの弾は背景に描く**。
- **背景**: 海は16行のテンプレートを敷き詰め、艦は 256×496 の絵を画面外のVRAMに一度だけ描く。
  表示は256行のリングで、縦スクロールはレジスタ1本（描き直しゼロ）。
- **拡大（MAG）**はスプライト全体に効くので、帯で区切って使う（最終面・5面の中ボス・津波）。
- フレームは30fps固定。1フレームの処理は VDP の転送待ちが支配的。
